# نادي آليات الشرطة الرياضي — V5 جاهز للرفع

هذه المرحلة توسّع V4 إلى نظام إداري أكبر، مع بقاء القسم العام للأخبار.

## ما تم تنفيذه فعلياً
- تسجيل الدخول بالهاتف أو الاسم الثلاثي وكلمة المرور.
- صلاحيات فردية يديرها مدير النظام.
- تغيير كلمة المرور وإجبار المستخدم الجديد على تغييرها.
- الكتب والمعاملات والوارد والصادر والأوامر الإدارية.
- التبليغات الموجهة للجميع أو لقسم محدد.
- الطلبات والموافقات: إجازة، إيفاد، شراء، صيانة، تكليف، موافقة.
- المهام والتكليفات.
- الاجتماعات وجدول الأعمال والمحاضر.
- الحضور والانصراف.
- المخزن والعهد والموجودات.
- الأخبار العامة.
- رفع وتنزيل الملفات مع قائمة امتدادات مسموحة وحد أقصى للحجم.
- إشعارات داخل النظام + Browser Notifications عند فتح التطبيق.
- نقطة تسجيل Push Token جاهزة للربط بـ Firebase FCM.
- التقارير وسجل التدقيق + تصدير CSV للمعاملات والدوام.
- PWA قابلة للتثبيت.
- Dockerfile و docker-compose للاستضافة.
- مشروع Android Studio محدث ويقرأ رابط الخادم من APP_URL.
- سكربت نسخ احتياطي لمجلد data.

## التشغيل محلياً
```bash
pip install -r requirements.txt
python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000
```
ثم افتح: http://127.0.0.1:8000

## حساب التطوير الأولي
- الاسم: مدير النظام
- الهاتف: 07700000000
- كلمة المرور: 123456

> الحساب الافتراضي للتجربة فقط. قبل أول تشغيل إنتاجي أنشئ ملف `.env` من `.env.example` وضع كلمة مرور قوية ومفتاح سري طويل. إذا كانت قاعدة البيانات قد أنشئت سابقاً، غيّر كلمة المرور من داخل النظام.

## النشر باستخدام Docker
1. انسخ `.env.example` إلى `.env` وعدّل القيم.
2. نفّذ: `docker compose up -d --build`
3. اربط النطاق وHTTPS عبر Nginx/Cloudflare أو مزود الاستضافة.

## Android
افتح مجلد `android` في Android Studio، وعدّل `APP_URL` داخل `android/gradle.properties` إلى رابط HTTPS الفعلي ثم ابنِ APK/AAB.

## Firebase
الإشعارات التي تصل والتطبيق مغلق تحتاج مشروع Firebase وملف `google-services.json` ومفتاح/بيانات FCM. لم تُضمَّن أي مفاتيح سرية داخل الحزمة.
